RVC Voice Conversion Trainer

A Runpod Serverless worker that trains official Retrieval-based Voice Conversion models from a zip of one speaker’s audio and returns an inference-ready .pth + .index.

GitHub Runpod Hub README

What you send / what you get

  • Send a dataset_url to a zip of wav/flac/mp3 clips of one target speaker. Transcripts are not needed.
  • Get <model_name>.pth and <model_name>.index, ready for the official WebUI or infer/cli.py.
  • Default: RVC v2, 40 kHz, F0=rmvpe, fp16, public pretrained weights (~0.55 GiB, no token).

Not the same as

  • GPT-SoVITS trainer — few-shot TTS / voice cloning.
  • Kokoro TTS — TTS inference only.

Example job

{
  "input": {
    "dataset_url": "https://example.com/voice.zip",
    "model_name": "my_speaker",
    "version": "v2",
    "sample_rate": "40k",
    "epochs": 200,
    "f0_method": "rmvpe"
  }
}
